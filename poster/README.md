# BeatEdit poster

Final A0 portrait poster for **BeatEdit: Symbolic Music Generation as Explicit Editing**.

- [Print-ready PDF](BeatEdit_Poster_A0.pdf) — one page, 841 × 1189 mm.
- [300-DPI PNG](BeatEdit_Poster_A0_300dpi.png) — 9933 × 14046 pixels.
- [Standalone HTML](poster_standalone.html) — all image assets embedded; open locally without a server.
- [Editable HTML/CSS](poster.html) — uses the images in `assets/`.

## Edit and export

Use a dedicated Python environment:

```bash
cd poster
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python tools/render.py
```

The renderer regenerates the PDF, PNG and standalone HTML from `poster.html`.
The final files were rendered on macOS with Helvetica Neue and Georgia; the
HTML declares Arial and Times New Roman as fallbacks on other systems.

To update the three URL QR codes:

```bash
.venv/bin/python tools/generate_qr.py --verify
.venv/bin/python tools/render.py
```

The supplied WeChat QR is a separate image and is not regenerated by that script.
